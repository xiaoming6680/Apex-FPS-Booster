# Apex 帧数优化工具

面向 Windows 的 Apex Legends 帧数优化工具，单文件 PowerShell + WinForms 图形界面，
无需安装、无依赖、无网络请求。所有改动可逐项还原。

> 作者 XIAOMING6680 · 仅在本机运行，不联网、不收集任何数据

---

## 特性

- **实时状态面板** — 15 项系统配置持续检测，绿灯/黄灯/红灯三色标注，后台线程刷新，不卡界面
- **显卡实时监控** — 频率 / 功耗 / 负载 / 温度（依赖 `nvidia-smi`，非 N 卡时该栏提示不可用，其余功能照常）
- **一键优化** — 电源方案、CPU 频率下限、MMCSS 游戏调度、Xbox 后台录制、显卡通道省电、Apex 独显指定等
- **可完整还原** — 首次操作前自动备份原始值与电源方案，还原后逐项读回校验，任何一项对不上都会标红
- **游戏前准备** — 释放系统缓存、按类别勾选结束占用后台的程序
- **瓶颈实测** — 采样 60 秒，定位性能卡在 CPU 还是 GPU
- **高分屏适配** — Per-Monitor DPI 感知，125% / 150% / 200% 缩放下均清晰
- **通用性** — CPU / 显卡 / 内存 / 分辨率运行时读取；Apex 路径经注册表 → `libraryfolders.vdf` → EA/Origin 常见目录逐级探测，找不到可手动指定

## 快速开始

1. 下载或克隆本仓库，保持所有文件在同一个文件夹内
2. 运行 `创建快捷方式.bat`，会在当前目录生成 `Apex 优化工具.lnk`（已带管理员标志、云朵图标）
3. 之后双击该快捷方式启动，不闪黑框

也可以直接运行 `Apex优化.bat`（备用启动器，会有极短一瞬的黑框）。

> 快捷方式内保存的是绝对路径，无法跨机器复制。换电脑或移动文件夹后，重新运行一次 `创建快捷方式.bat` 即可。

**需要管理员权限。** 未提权时程序会直接拦住并提示重新启动，不会让你在"所有修改都静默失败"的状态下白点。

## 还原机制

1. **首次操作前先备份** — 点"一键优化"或"关闭虚拟化安全"之前，把每一个将要修改的值原样存到
   `%LOCALAPPDATA%\ApexOptBackup\backup.txt`，同时用 `powercfg -export` 完整导出原电源方案到
   `orig_scheme.pow`。备份只生成一次，之后绝不覆盖 —— 防止把已优化的状态误当成原始状态存进去。
2. **绝不改动已有电源方案** — 优化时新建一个独立方案再改，原方案一个都不碰。还原 = 切回原方案 + 删除新建的。
3. **逐条读回，不写死默认值** — `NOTSET` 表示该项原本不存在，还原时删除而非猜一个值。
4. **还原后自动校验** — 逐项重新读取并与备份比对，全部一致才显示"已完全还原到初始状态"。

每个大操作结束后都会弹出结果窗口，逐条列出做了什么、结果如何。窗口里的每一条都是执行完**重新读取的真实值**，
不是"我发过这条命令所以应该成功了"。

## 风险提示

- **一键优化**把处理器最小状态设成 100%，待机温度会升高。笔记本散热弱时可能触发温度墙反而掉帧 ——
  发现变烫或掉帧就点"还原全部设置"。
- **关闭虚拟化安全（VBS）** 会禁用 Hyper-V，Docker / WSL2 将不可用。
- **关闭 VBS 会改动启动配置（bcdedit）。** 如果系统盘开着 BitLocker / 设备加密，下次开机可能要求输入 48 位恢复密钥，
  拿不出来就进不了系统。微软账户登录的品牌机、笔记本默认就开着设备加密，很多人并不知道。
  程序会在确认框里检测并单独警告 —— 看到警告请先到 <https://aka.ms/myrecoverykey> 确认能取到密钥再决定。
  这项只值 5~10% 帧数，不确定就别关。
- **游戏前准备**中被勾选的程序会被强制结束，未保存内容会丢失。

## 关于"帧数跑不满"

Apex 引擎硬上限 300 帧，且极度依赖 CPU 单核性能。分辨率越高、场景越复杂，越不可能吃满 300。

画质已经压到底还上不去时，看"显卡实时"那栏 —— 负载长期上不去说明瓶颈在别处，不是显卡的问题。

要手感稳定而非数字好看，`fps_max` 锁 190 或 240 通常比放开更舒服：帧生成时间平稳，不会在 300 和 160 之间横跳。

## 一个额外的修复

点"一键优化"时会先自检系统 MMCSS 多媒体任务配置是否完整（注册表
`HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Multimedia\SystemProfile\Tasks` 下应有 9 项）。

网上流传的部分"游戏优化"脚本和 `.reg` 文件会误删这些项，导致全系统音视频都放不出来（播放器报错 `0xC00D11B1`）。
检测到缺失会自动按 Windows 出厂默认值补回并重启 MMCSS 服务。系统正常时这一步什么都不做。

注意："还原全部设置"不会撤销这项修复 —— 那 9 项是 Windows 本来就该有的东西。
